1. Nitro Optimizer - Windows Edition v2.0

Archivo: .bat - Windows 10 y 11.

Plan Alto Rendimiento, desactivar efectos, Game DVR, SysMain, matar Defender, Cortana, Copilot, OneDrive, Edge, cortar telemetria, limpiar temporales, optimizar red, MODO DIABLO [29], punto de restauracion [30].

Descargar desde GitHub
  1. Descarga .bat v1.2-Estable.
  2. Clic derecho > Ejecutar como administrador.
  3. Primero [30] crear punto.
  4. Despues [01], [02], [11] o [29] MODO DIABLO.
  5. No cierres hasta LISTO. Reinicia. Si falla [R] Restaurar.

2. Nitro Optimizer - Android Edition v1.0

Archivo: .py - NO es APK, se corre en la PC con ADB.

Cualquier Android sin root. Borra bloatware Google, ZTE, Samsung, Xiaomi.

Descargar desde GitHub
  1. Celular: Ajustes > Acerca del telefono > toca 7 veces Numero de compilacion > Depuracion USB ON.
  2. Conecta con cable original, PERMITIR, cambia USB a Transferir archivos.
  3. PC Windows: Python con Add to PATH, CMD, cd Descargas, python Nitro-Optimizer-Android-Edition.py, 1 Instalar ADB, 2 Conectar Celu, 3 NITRO OPTIMIZAR!
  4. MAC: brew install python, brew install android-platform-tools, python3 Nitro-Optimizer-Android-Edition.py
  5. LINUX: Arch sudo pacman -S android-tools tk, Ubuntu sudo apt install adb python3-tk

4. NitroOS11-PRO

NitroOS - Basado en Tiny11, optimizado y personalizado por nitro-opti.

Dato realValor
ISO pesa6.3GB
Procesos73 procesos
RAM usa1.8GB de RAM

Defender, Windows Update y Store eliminados desde raiz. Incluye Nitro Toolbox, Brave, drivers en C:\NitroOS\Installers.

Post-install 1: Automatica, verificacion + CompactOS. Post-install 2: Manual Nitro Toolbox, nada sin preguntar. Menu: 1 drivers, 2 dependencias, 3 rendimiento, 4 privacidad, 5 limpiar, 20 navegadores, 21 apps, 30 Nitro Ultimate, 31 Espanol, R restaurar, X salir.

Descargar ISO desde Drive (6.3GB)
  1. Descarga ISO 6.3GB.
  2. USB con Ventoy o Rufus.
  3. Reinicia, F12, elige USB.
  4. Instala, va directo a escritorio con autounattend.xml.
  5. Espera post-install automatica.
  6. Abre Nitro Toolbox, corre 1, 2, 3, 4, 30.
  7. Para navegadores 20, para apps 21.
  8. Reinicia, verifica 73 procesos y 1.8GB RAM.
