Nitro Optimizer Android Edition v1.0 .py, no es APK

Archivo .pyCon ADB desde la PC

Que es

Un archivo .py para optimizar Android desde la PC con ADB. No es APK, no se instala en el celular.

Como instalarlo

  1. En la PC instala Python y android-tools (ADB).
  2. Descarga el .py desde GitHub.

Como usarlo

  1. En el celular activa Opciones de desarrollador > Depuración USB.
  2. Conecta el celular por USB y acepta la depuración.
  3. En la PC corre: python nitro-optimizer-android.py
  4. Sigue el menu en la terminal.

Nitro Linux v1.0 Base Arch, Hyprland + Serpantinum

ISO ~2.0 GBBase ArchKernel linux-cachyosHyprland + SerpantinumFirefox, Thunar, Mousepad, Foot, Calamares, OpenCode

Que es

Sistema con base Arch, kernel linux-cachyos, Hyprland + Serpantinum, con el wallpaper fijo. Solo lo esencial.

Como instalarlo

  1. Descarga la ISO desde Drive.
  2. Crea un USB con Ventoy o Etcher.
  3. Arranca en modo UEFI-only.
  4. Entra solo con autologin, sin login ni contraseña.
  5. Welcome automático, Calamares se abre solo a los 4 segundos sin pedir contraseña, instala, crea tu usuario, reinicia.

Como usarlo

Prende, ya estás dentro, wallpaper intacto, welcome automático. Atajos: Mod+T terminal, Mod+D launcher, Mod+I instalador. WiFi, Bluetooth, sonido y impresora con GUI.
