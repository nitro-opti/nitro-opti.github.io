Nitro Linux v1.0 Base Arch, Niri + Noctalia

ISO 1.8 GiBBase ArchKernel linux-cachyos 7.3.3Niri + Noctalia611 paquetesFirefox, Thunar, Mousepad, Foot, Calamares, OpenCode v2.3.0

Que es

Sistema con base Arch, kernel linux-cachyos 7.3.3, escritorio Niri + shell Noctalia. Solo lo esencial.

SHA256: 539e2afa1215cf46f69a022244045f639b7bf5fae734465d1c5fffe92a6a5871

Como instalarlo

  1. Descarga la ISO desde Drive y verifica el SHA256.
  2. Crea un USB con Ventoy o Etcher.
  3. Arranca en modo UEFI-only.
  4. En systemd-boot elige Nitro Linux v1.0.
  5. En el live entra con usuario nitro / contraseña nitro.
  6. Presiona Mod+I para abrir Calamares, instala, crea tu usuario, reinicia.

Como usarlo

Prende, abre Firefox, WiFi, Bluetooth y sonido ya funcionan, sin tocar la terminal.

QEMU

Usa -cpu host, es clave. Con qemu64 OpenCode (Bun) falla por falta de SSE4.2.

cp /usr/share/edk2/x64/OVMF_VARS.4m.fd /tmp/nitro-ovmf-vars.fd
qemu-system-x86_64 -m 2048 -smp 2 -enable-kvm -cpu host -drive if=pflash,format=raw,readonly=on,file=/usr/share/edk2/x64/OVMF_CODE.4m.fd -drive if=pflash,format=raw,file=/tmp/nitro-ovmf-vars.fd -cdrom nitro-linux-1.0.0-x86_64.iso
